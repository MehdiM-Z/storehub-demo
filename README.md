# 🛍️ StoreHub | فروشگاه اینترنتی

**StoreHub** یک پلتفرم فروشگاهی مدرن با هدف ایجاد تجربه‌ای کامل و یکپارچه برای خرید آنلاین و مدیریت فروشگاه است. این پروژه با تمرکز بر طراحی رابط کاربری جذاب، ساختار توسعه‌پذیر و امکانات متنوع برای مشتریان و مدیران فروشگاه طراحی شده است.

## 🌐 نسخه نمایشی

[مشاهده فروشگاه StoreHub](https://mehdim-z.github.io/storehub-demo/)

> **توجه:** نسخه آنلاین منتشرشده، یک نسخه نمایشی و ساده‌شده از پروژه اصلی است و تنها بخش کوچکی از قابلیت‌ها و امکانات StoreHub را به نمایش می‌گذارد. برخی امکانات در این نسخه به‌صورت آزمایشی یا شبیه‌سازی‌شده در دسترس هستند و تمام قابلیت‌های نسخه کامل در آن فعال نیستند.

## 📌 معرفی پروژه

StoreHub یک پروژه فروشگاهی با هدف فراهم‌کردن بستری جامع برای خرید آنلاین و مدیریت فروشگاه است.

در نسخه کامل پروژه، امکاناتی مانند مدیریت محصولات و دسته‌بندی‌ها، کاربران، سفارش‌ها، پرداخت‌ها، محتوای صفحه اصلی، تنظیمات ظاهری و پنل مدیریت در نظر گرفته شده است.

ساختار ماژولار و توسعه‌پذیر پروژه امکان گسترش و افزودن قابلیت‌های جدید را فراهم می‌کند.

## ✨ امکانات اصلی

### 🛒 فروشگاه و مشتریان
- نمایش محصولات و دسته‌بندی‌ها
- جستجو، فیلتر و مرتب‌سازی محصولات
- مشاهده جزئیات محصولات
- سبد خرید و علاقه‌مندی‌ها
- ثبت‌نام و ورود کاربران
- مدیریت پروفایل و آدرس‌ها
- ثبت و پیگیری سفارش‌ها
- فرآیند پرداخت

### ⚙️ مدیریت فروشگاه
- داشبورد مدیریتی
- مدیریت محصولات و دسته‌بندی‌ها
- مدیریت سفارش‌ها و کاربران
- مدیریت محتوای صفحه اصلی
- تنظیمات ظاهر و قالب فروشگاه
- مدیریت سطح دسترسی کاربران

### 🎨 رابط کاربری
- طراحی مدرن و واکنش‌گرا
- پشتیبانی از حالت روشن و تاریک
- تجربه کاربری یکپارچه
- ساختار کامپوننت‌محور

## ⚠️ محدودیت‌های نسخه نمایشی

- نسخه آنلاین صرفاً برای معرفی و نمایش بخشی از امکانات پروژه منتشر شده است.
- اطلاعات آزمایشی در مرورگر و LocalStorage ذخیره می‌شوند.
- پرداخت‌ها شبیه‌سازی‌شده هستند و تراکنش واقعی انجام نمی‌شود.
- برخی قابلیت‌های وابسته به بک‌اند در این نسخه فعال نیستند.
- امکانات نسخه کامل لزوماً در نسخه نمایشی قابل دسترسی نیستند.
