## 📌 معرفی پروژه

<p dir="rtl" align="right">
  <bdi dir="ltr">StoreHub</bdi> یک پروژه فروشگاهی با هدف فراهم‌کردن بستری جامع برای خرید آنلاین و مدیریت فروشگاه است.
</p>
در نسخه کامل پروژه، امکاناتی مانند مدیریت محصولات و دسته‌بندی‌ها، کاربران، سفارش‌ها، پرداخت‌ها، محتوای صفحه اصلی، تنظیمات ظاهری و پنل مدیریت در نظر گرفته شده است.

ساختار ماژولار و توسعه‌پذیر پروژه امکان گسترش و افزودن قابلیت‌های جدید را فراهم می‌کند.

## ⚠️ محدودیت‌های نسخه نمایشی

- نسخه آنلاین صرفاً برای معرفی و نمایش بخشی از امکانات پروژه منتشر شده است.
- اطلاعات آزمایشی در مرورگر و LocalStorage ذخیره می‌شوند.
- پرداخت‌ها شبیه‌سازی‌شده هستند و تراکنش واقعی انجام نمی‌شود.
- برخی قابلیت‌های وابسته به بک‌اند در این نسخه فعال نیستند.
- امکانات نسخه کامل لزوماً در نسخه نمایشی قابل دسترسی نیستند.
